# Python Coursework Activities

This repository contains Python activities and assignments completed for coursework.

## Projects & Activities

### 1. CLI BMI Calculator (`bmi_calculator.py`)
* **Week 1:** Implemented a Command-Line Interface (CLI) Body Mass Index calculator using procedural functions and error handling.
* **Week 2:** Refactored the CLI calculator to use an **Object-Oriented Programming (OOP)** design pattern with custom classes and methods.

## How to Run
